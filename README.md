# Jogo da Velha(Tic-Tac-Toe)

Um jogo da velha clássico implementado em Python para ser jogado diretamente no terminal. O projeto foca na lógica do backend e na interação via console.

## Como Jogar

1. Certifique-se de ter o Python instalado.
2. Clone o repositório:
   ```bash
   git clone https://github.com
   ```
3. Navegue até a pasta do projeto:
   ```bash
   cd nome-do-repositorio
   ```
4. Execute o jogo:
   ```bash
   python main.py
   ```
## Regras do Jogo

* Os dois decidem quem começa a partida.
* Turnos alternados: Cada jogador, na sua vez, coloca o seu símbolo (X ou O) em apenas uma das casas que estiver vazia.
* Sequência: O jogo continua com os participantes alternando as jogadas até que alguém vença ou todos os espaços fiquem preenchidos.

## Tecnologias
* Python (Biblioteca padrão).

## Funcionalidades
* Jogo para 2 jogadores (sem player vs machine).
* Validação de jogadas (não permite jogar em posições ocupadas ou inválidas).
* Verificação automática de vitória ou empate (velha).
